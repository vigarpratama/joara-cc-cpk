# Platform Configuration Notes
# ================================
# File ini menjelaskan konfigurasi per platform yang dibutuhkan.
# Jalankan perintah berikut untuk men-generate folder platform:
#
# flutter create --platforms=android,ios,windows,macos .
#
# Setelah itu folder berikut akan otomatis terbuat:
#   android/   → untuk Android
#   ios/       → untuk iOS (butuh macOS + Xcode)
#   windows/   → untuk Windows Desktop
#   macos/     → untuk macOS Desktop
